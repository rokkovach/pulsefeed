# Report assets

These are reviewed public assets for the six-page report.

- `review-architecture.svg` and `.png`: compact report architecture diagram.
- `reader.png`: actual local BBC England reader with 512-square images generated by live Runpod workers.
- `admin-overview.png`: actual local shared allowance dashboard.
- `admin-models.png`: actual aggregate Qwen token chart and table.

The screenshots were captured on 20 October 2026 from existing authenticated local pages, without creating jobs or changing policy. They contain no credentials, session links or visitor identifiers. Dashboard totals include later exploratory use; they are not the controlled ten-image sample in the validation report.

Text, tables and captions remain editable in the Word report. Diagram SVGs are editable; PNGs can be reused in email, slides or Word. Other technical diagrams are in [the diagrams folder](../../diagrams/README.md).
